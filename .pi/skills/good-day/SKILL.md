# Good Day Greeting Skill

## 동작 조건

사용자가 다음 문구를 입력하면 이 스킬을 사용합니다.

```text
좋은하루
```

## 응답 규칙

사용자가 `좋은하루`라고 입력하면 반드시 아래 문구로 응답하세요.

```text
안녕하세요 주인님 오늘은 무엇을 도와드릴까요?
```

## 주의사항

- 사용자가 정확히 `좋은하루`라고 입력한 경우에는 다른 설명을 덧붙이지 않습니다.
- 응답은 한 줄로만 출력합니다.
- 도구 호출은 필요하지 않습니다.
